## 🚀 Resumen del Caso de Estudio

El proyecto aborda la problemática de control de inventario y registro transaccional de un comercio minorista de víveres y papelería. 

### Objetivos Clave:
1. **Control en tiempo real:** Gestión del stock directo en estantes (sin depósito secundario).
2. **Arqueo de caja:** Clasificación de ingresos según modalidad de cobro (**Efectivo** vs. **QR**).
3. **Reabastecimiento eficiente:** Alerta visual de productos que alcanzaron su nivel de `stock_minimo`.
